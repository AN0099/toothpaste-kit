# Code of Conduct

## The standard

Participation in this project is open to anyone who can work with others civilly. Harassment,
personal attacks, demeaning comments, and unwelcome attention are not acceptable in any project
space, and neither is publishing someone's private information without their permission.

Two things this project asks for beyond the baseline, because they are load-bearing here:

**Disagree in the open.** `CONTRIBUTING.md` asks that findings be raised rather than quietly
resolved, and that applies to disagreement about conduct and process as much as it does to code. A
unilateral fix hides the disagreement that prompted it.

**Assume the other person is working from different information.** Most conflict in a distributed
project is a context gap rather than bad faith. Ask what someone knows before deciding what they
meant.

## Scope

Any space this project uses: the repository, its issues and pull requests, and any venue where
someone is representing the project.

## Accessibility is not a courtesy here

This project's stated premise is that an interface is only an interface for the people who can
operate it. Dismissing an accessibility concern, or treating an accommodation request as a
distraction from the real work, is a conduct problem in this repository specifically, because it
contradicts the thing the project exists to argue.

## Reporting

Report to `an0099+conduct@proton.me`. Reports are handled privately.

Know the shape of this project before you write. It has one maintainer, and that address reaches
that person directly. There is no independent body to escalate to, because there is not yet a
project large enough to have one. Saying so is better than implying a process that does not exist.

If a report concerns the maintainer, say so and name a third party you would accept. The project
will route it that way rather than ask you to file with the subject of your complaint.

## What happens next

The maintainer will acknowledge a report, look into it, and say what was decided. Depending on
what happened, that ranges from a private word, through a warning and a request for a public
apology, to a temporary or permanent ban from project spaces. Enforcement decisions and their
reasons are recorded privately.
