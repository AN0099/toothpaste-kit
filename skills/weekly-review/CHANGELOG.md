# CHANGELOG

## v1 (initial)

The once-a-week pass over a task board's slower lanes, the second of the reviews that
`daily-review` named and the kit did not ship. The daily pass sees what arrives and what is next.
It does not see a blocker that stopped being true, a task carried a day at a time, or an important
task that loses to something urgent every morning.

Three things are deliberate.

**A scheduled task gets a day, never a due date.** In this kit a due date with a consequence is what
makes a task urgent. Giving an important task a deadline to get it done would move it into Do and
hide the starvation the step exists to show.

**A carried task is a question about the plan.** Step 2 proposes splitting, returning or keeping a
task, and asks which part of the plan was wrong. It never asks who was slow.

**The Done lane is read back against each task's own verification.** A close that rested on a
different check from the one written at the start is named, not reopened, so the next task states
its check more honestly.
