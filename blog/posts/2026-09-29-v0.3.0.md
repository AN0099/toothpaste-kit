Version 0.3.0 is a MINOR release under `docs/releasing.md`. It adds one skill and a release
cadence, and it changes documentation and skill files only: no script changed.

## A daily review

The new skill, `skills/daily-review/`, is a once-a-day pass over a task board's lanes:

- the Inbox is clarified to empty;
- carried work is counted;
- finished work is offered for close;
- priority is read as an Eisenhower quadrant;
- and the day's order is proposed.

It proposes and asks, and it moves nothing the person did not answer. It assumes a lane-board
tool, and it says what that tool must print. `README.md` and `docs/project-state.md` now list
fifteen skills, with `daily-review` among those a person invokes.

## A release cadence

`docs/releasing.md` has a new Cadence section. A release review happens every two weeks on a
Tuesday, with a Friday cutoff and a Monday final review, and there is a release only when the
review admits one.

## Citing the kit

`CITATION.cff` now lists only the concept DOI, which is the one to cite. Each version DOI is
recorded under "Where releases stand" in `docs/releasing.md` by the release after it, so a release
no longer needs a follow-up pull request to record its DOI. Steps 3 and 7 of `docs/releasing.md`
say so.

## Also changed

In `docs/quickstart.md`, the example `CLAUDE.md` names the provenance layer and the file that lists
the standing files, which the loop skills look for before writing.
